# Frozen evaluation plan (NOT_RUN for model quality)

18 synthetic draft cases in three domains, one development and five held-out document groups per domain. Gold outcomes were authored before any model execution; model_result remains null. These are a starting protocol, not a calibrated or complete production benchmark. Have a domain reviewer confirm the indirect software-dependency interpretation before scoring; do not silently change gold after seeing outputs.

Materialize each source into an isolated KB with declared endpoint classes and the specified existing property when supplied. Add the canonical missing relation only through the future reviewed proposal path. Compare fixed structured answer pairs before/after adoption and verify no unapproved mutation. Explicitly test three supply documents together for forward/reverse alignment and separate evidence/document counts. The one-sentence records are independent seed cases; the multi-document lifecycle fixture still needs implementation after ADR.

Run each configuration twice on all three domains; keep request/response, provider/model/prompt IDs, tokens, errors and actual human amendments. Group train/demo versus held-out by documents/entities, not name substitutions. Score wrong additions (duplicate, direction, unsupported separately), correct reuse, fixed query answers, new correct and wrong typed facts, unchanged unrelated facts and repeated-run proposal count. State the denominator for every metric. Calibrate any model judge against human labels and report disagreement. Scripted mocks do not establish proposal quality. No real-provider calls, token charges or quality percentages are claimed in this delivery.

Calibration clarification after independent review: no_target_relation_proposal rejects only the target affirmative relation; citation or optional use may justify some other property. expected_answers always means final target-relation pairs for that case, not newly created schema or answer delta; reuse cases therefore include their expected pairs. A runner must not score other legitimate relation proposals as universal errors merely from this label.
